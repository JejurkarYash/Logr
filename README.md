# Logr

A personal developer progress tracker to log daily work, maintain streaks, and stay consistent.

## Features

* Daily logs (hours, wins, blockers)
* Streak tracking
* Weekly insights
* Milestone tracking (OSS + users)

## Tech Stack

* Next.js 14
* Supabase (Auth + Database)
* Tailwind CSS
* Recharts

## Goal

Stay consistent. Build daily. Track everything.
